# Poom Voice WebSocket Server

## 설정

1. **가상환경 및 의존성**
```bash
python>=3.12
```

```bash
python -m venv .venv
.venv\Scripts\activate   # Windows
pip install -r requirements.txt
```

## 실행

```bash
.venv\Scripts\activate
python main.py
```
