WebSocket 메시지 형식 확인

REST의 message/reply처럼, WebSocket에서 어느 필드에 입력·출력이 저장되는지 참고용.

필드 매핑 (입력 → 출력)

구분저장/전달 위치형식
사용자 음성 (입력)클라이언트 → 서버 Binary 메시지 전체PCM 바이트. JSON 필드 없음.
사용자 발화 텍스트서버 → 클라이언트 Text 메시지 내 user_textJSON
AI 음성 (출력)서버 → 클라이언트 Binary 메시지 전체PCM 바이트. JSON 아님.
AI 답변 텍스트서버 → 클라이언트 Text 메시지 내 ai_textJSON

서버 → 클라이언트 JSON 예시 (말풍선용)

{"user_text": "오늘 기분이 어때?", "ai_text": null}
{"user_text": null, "ai_text": "저도 좋아요. 무엇을 도와드릴까요?"}

수신 메시지 로그 (직접 확인)

연결 후 서버가 보내는 메시지를 실시간으로 표시. Binary = ai_voice, Text = user_text/ai_text JSON.

입력·응답 텍스트가 서버에 안 보일 때: 음성 대화 시 사용자 발화(user_text)·AI 응답(ai_text)은 서버를 띄운 터미널에 [voice] user_text: ..., [voice] ai_text: ... 로 출력됩니다. 이 페이지는 클라이언트가 수신한 메시지만 표시합니다. (실제 대화는 /demo 에서 마이크로 하면 터미널에 로그가 찍힙니다.)
